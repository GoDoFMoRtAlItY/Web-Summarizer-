Web Summarizer is my first ever made chrome extention for any chromium based browser. 

It summarizes the contents shown in the browser in three different methods :

<img width="109" height="97" alt="image" src="https://github.com/user-attachments/assets/e1c0a08c-0774-4635-a587-feef388da5d3" />

Brief: For a short Summarization of the page.
Detailed: For a Overall in depth summarization of the page.
Bullet Point: For summarizing the page in 5 to 7 bullet points
